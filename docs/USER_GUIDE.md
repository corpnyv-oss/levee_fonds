## Guide Administrateur

### Gestion des Utilisateurs

#### Créer un Nouvel Utilisateur
1. Connectez-vous au panneau d'administration
2. Allez dans la section "Utilisateurs"
3. Cliquez sur "Ajouter un utilisateur"
4. Remplissez les informations requises
5. Attribuez les rôles appropriés

#### Gérer les Permissions
- Les rôles disponibles sont :
  - **Administrateur** : Accès complet au système
  - **Gestionnaire** : Peut gérer les cagnottes et les dons
  - **Utilisateur** : Peut faire des dons et gérer son profil

### Gestion des Cagnottes

#### Créer une Nouvelle Cagnotte
1. Allez dans "Cagnottes" > "Nouvelle cagnotte"
2. Remplissez les détails :
   - Titre et description
   - Montant objectif
   - Date limite
   - Image de couverture
3. Enregistrez la cagnotte

#### Modifier/Supprimer une Cagnotte
- Utilisez les boutons d'action dans la liste des cagnottes
- La suppression est définitive et irréversible

### Suivi des Paiements

#### Voir les Statistiques
- Tableau de bord avec :
  - Montant total collecté
  - Nombre de donateurs
  - Évolution des dons dans le temps

#### Exporter les Données
1. Allez dans "Rapports"
2. Sélectionnez la période
3. Choisissez le format d'export (CSV, Excel, PDF)
4. Téléchargez le rapport

### Configuration du Système

#### Paramètres de Paiement
1. Allez dans "Paramètres" > "Paiements"
2. Configurez les passerelles de paiement
3. Définissez les frais éventuels

#### Paramètres de Notification
1. Allez dans "Paramètres" > "Notifications"
2. Configurez les modèles d'emails
3. Activez/désactivez les notifications

## Guide Donateur

### Créer un Compte
1. Cliquez sur "S'inscrire"
2. Remplissez le formulaire
3. Validez votre adresse email
4. Connectez-vous avec vos identifiants

### Faire un Don
1. Parcourez les cagnottes disponibles
2. Sélectionnez une cagnotte
3. Choisissez le montant
4. Sélectionnez le mode de paiement
5. Confirmez le paiement

### Suivre ses Dons
1. Connectez-vous à votre compte
2. Allez dans "Mes Dons"
3. Consultez l'historique et les reçus

### Gérer son Profil
1. Cliquez sur votre nom en haut à droite
2. Sélectionnez "Mon Profil"
3. Mettez à jour vos informations
4. Activez l'authentification à deux facteurs pour plus de sécurité

## FAQ

### Comment annuler un don ?
Les dons ne peuvent pas être annulés après validation du paiement. Contactez le support pour toute demande exceptionnelle.

### Quand vais-je recevoir mon reçu ?
Les reçus sont générés automatiquement après validation du paiement et envoyés par email sous 24h.

### Comment contacter le support ?
Utilisez le formulaire de contact sur le site ou envoyez un email à support@votredomaine.com.

### Les dons sont-ils sécurisés ?
Oui, tous les paiements sont chiffrés et sécurisés. Nous utilisons des protocoles de paiement certifiés.

### Comment savoir à quoi servent mes dons ?
Chaque cagnotte contient une description détaillée de son objectif et de l'utilisation des fonds collectés.
